TinDog completed Bootstrap project

Files:
- index.html
- css/style.css

How to run in VS Code:
1. Open the tindog-complete folder in VS Code.
2. Open index.html.
3. Right-click and choose "Open with Live Server" (if installed), or double-click index.html in File Explorer.
4. Keep internet on because Bootstrap and the TinDog image assets are loaded from CDNs/GitHub.

For GitHub Pages:
1. Upload index.html and the css folder to your repository root.
2. In GitHub: Settings > Pages.
3. Deploy from the main branch/root folder.
